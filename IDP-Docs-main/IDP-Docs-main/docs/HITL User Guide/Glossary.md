## Summary

The **Glossary** tab provides a centralized reference for all terms, KPIs, and metrics used across the **Executive Dashboard**, **AI Metrics**, **Pricing**, and **Deep Dive Data** sections. It helps users understand metric definitions, how calculations are performed, and how each value contributes to operational, accuracy, and cost insights.

This tab is especially useful for onboarding new analysts, ensuring consistent interpretation of reports, and maintaining transparency in how KPIs are derived.

## Dashboard

![Glossary](../HITL%20User%20Guide/UI%20Screens/Quicksight/AI%20Metrics/Glossary.png)

The glossary table contains three columns:

- **Term** – The KPI or operational attribute.
- **Description** – A plain‑language explanation of what the metric represents.
- **Formula** – Calculation used to derive the metric, when applicable.
