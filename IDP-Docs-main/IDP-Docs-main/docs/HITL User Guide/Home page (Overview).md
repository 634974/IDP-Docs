
## Review page (default landing page)

After you sign in to the IDP HITL portal, the system redirects you to the **Review** page. Use this page to monitor the review workload and access tasks that are pending, in progress, completed, or rejected.

### Left navigation

Use the left navigation panel to open the following sections:

- **Review**: View and manage tasks that require review.  
  See: [Review](Review%20page.md)

- **Reject**: View tasks that have been rejected.  
  See: [Reject](Reject%20page.md)

- **Admin**: Administrative functions.  
  See: [Admin](Admin%20Page.md) 

- **Reports**: Analytics and reporting (QuickSight).  
  See: [Reports](Reports.md)
