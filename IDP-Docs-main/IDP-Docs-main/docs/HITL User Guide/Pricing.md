## Summary

The **Pricing** tab provides a unified view of usage‑driven costs incurred by the IDP pipeline, including **LLM (Bedrock) token consumption**, **Textract usage**, and **the overall blended cost** for a selected timeframe. This tab helps supervisors, program managers, and finance/ops teams quantify spend, validate budget assumptions, and track cost trends as volumes fluctuate across document types and languages.

---

## Overview Metrics

![pricing](../HITL%20User%20Guide/UI%20Screens/Quicksight/AI%20Metrics/Pricing.png)

At the top of the dashboard, a set of **[global filters](Reports.md#filters-controls)** enables precise cost slicing:

- **Date Range** – Restrict metrics to a specific time window (supports Day/Month/Quarter/Year drill‑down).
- **Needs HITL Review** – Include or exclude items that required human review.
- **Language Code** – Compare costs across languages.
- **DocType** – Identify document types with the highest cost footprint.
- **Status** – Filter on completed/valid cases for financial reconciliation.
- **FileName** – (When needed) isolate specific documents for audit.

A Drill‑Down Date control below the KPIs lets you quickly switch between Daily, Monthly, Quarterly, and Yearly trend views.

### Top KPIs
The following KPIs summarize the pricing and usage posture for the selected filter scope:


1. **Total Pages Digitized**

    Total number of pages processed by the pipeline (a primary cost driver for OCR).


2. **Bedrock I/P Tokens (Input Tokens)**

    Aggregate count of input tokens sent to LLMs (e.g., prompts, system instructions).


3. **Bedrock O/P Tokens (Output Tokens)**

    Aggregate count of tokens generated by LLMs (model responses).


4. **Textract Calls (Avg)**

    Average number of Textract API invocations per case, indicating the intensity of OCR usage (e.g., multi‑pass extraction, re‑tries, or page‑wise calls).


5. **Overall Cost**

    Total blended cost across Textract and LLM (Bedrock) for the selected period/filters.


6. **Bedrock Cost**

    Token‑based LLM cost component only.


7. **Textract Cost**

    OCR‑based cost component only (primarily driven by pages).

## Visualizations

### Cost Distribution

A distribution chart breaks down costs by your selected dimension (commonly Date, DocType, or Language).
Use the Date Drill‑Down control to analyze:

- Daily spikes (re‑tries, abnormal document sets)
- Monthly/Quarterly trends for budget cycles
- Yearly aggregates for annual planning
