### Login and session handling

1. Open the HITL portal URL: `https://hitl.prod.digital-idp.maximus.com/review/`
2. Sign in using SSO.
3. If your session expires due to inactivity, log in again and return to the Tasks page.

!!!Note
    To view documents for a specific tenant, you must have the appropriate access, which is granted by the IDP Administrator.

Once the user logged in they can see this screen.
